# Fake News Detection

This project uses Python and machine learning to classify news articles as **FAKE** or **REAL**. It leverages a TF-IDF Vectorizer for text feature extraction and a Passive Aggressive Classifier for accurate prediction. The project also includes a user-friendly Streamlit web app for interactive news verification.

---

## Features

- Detects fake and real news using machine learning
- Uses TF-IDF vectorization for text processing
- Implements a Passive Aggressive Classifier with ~92% accuracy
- Provides a Streamlit web interface for easy testing of news articles
- Displays model accuracy, confusion matrix, and classification report
