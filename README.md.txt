# Fake News Detection with Python & Streamlit

This project detects whether a news article is **FAKE** or **REAL** using machine learning techniques with TF-IDF vectorization and a Passive Aggressive Classifier.

## Features

- Text preprocessing with TF-IDF vectorization
- Machine learning classification using PassiveAggressiveClassifier
- Streamlit web app for interactive news prediction
- Confusion matrix and classification report for model evaluation

## Dataset

The dataset `news.csv` contains news articles labeled as FAKE or REAL.
